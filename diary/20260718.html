C - Adjacent Sums (easy)
(57:41 1x)


int main(void){
    int n, m; cin >> n >> m;
    vector<int> a(n), b(n-1);
    int i;
    rep(i,n) cin >> a[i];
    rep(i,n-1) cin >> b[i];

    auto c = a;

    ll ans1 = 0;
    rep(i,n-1){
        if((a[i]+a[i+1])%2 != b[i]){
            a[i+1]++;
            ans1++;
        }
    }
    ll ans2 = 1; c[0]++;
    rep(i,n-1){
        if((c[i]+c[i+1])%2 != b[i]){
            c[i+1]++;
            ans2++;
        }
    }
    
    cout << min(ans1, ans2);
}

最初適当に貪欲してペナ食らった　適当でいいわけないです
とはいえ\(M=2\)なので、下記より二回貪欲すると答えを出せる

操作後の数列を\(tg\)とすると、\(tg[0]\)を何かしら決めたとき、
\(tg[n] \equiv b[n-1] - tg[n-1]\)
より\(tg\)を全部決めれる
(操作回数を最小にしたいので、\(tg[n]\)はこれと、\(tg[n] \ge a[n]\)を満たす最小のものを選ぶ)
\(\mod 2\)をとるので、（\(a[0] + 2\)は\(a[0]\)の下位互換だから、）あり得る\(tg[0]\)は\(a[0]\)と\(a[0]+1\)の2通りしかないので、この二つを試せば十分

int main(void){

        if(a.second != b.second) return a.second < b.second;

Cと同様の議論でまずは\(M\)通りに\(tg\)を絞れる
\(M\)通りのうち\(tg[0]\)の操作回数が\(0\)のものについての第\(i\)項の操作回数を\(c[i]\)とすると、
操作回数が\(x\)の時の第\(i\)項の操作回数\(d_x[i]\)は
\(d_x[i]= (c[i] + (-1)^i x )\mod M \) と求められる(iは0indexed)
（a[0]を一回多く操作したなら、条件を達成するためにa[1]の操作数を1回減らす必要がある...といった感じで）
そしたら、一旦\(\mod M\)を無視すると
\(\sum_{i=0}^N d_x[i] = \sum_{i=0}^N c[i] +0\) (\(N\)が偶数の時)
\(\sum_{i=0}^N d_x[i] = \sum_{i=0}^N c[i] +x\) (\(N\)が奇数の時)
となって、modを取ることによる変動は、各\(i\)で
\(c[i]+x \ge M\)なる\(x\)で\(-M\) (\(i\)が偶数の時)
\(c[i]-x \lt 0\) なる\(x\)で\(+M\) (\(i\)が奇数の時)
で、基本的に\(x\)を増やすことは損なのでこの変動があるタイミングだけ気にするとよい
\(|c|=N\)なので、\(O(N)\)で求められます
